# Gemini Assistant Context

This is a macOS application for generating audio signals.

**Technologies**:
- Swift 5.9+
- SwiftUI
- AVFoundation
- XCTest
- AudioKit Flow (MIT) - for visual block editing
- Native SwiftUI Canvas and Drag & Drop

**Project Structure**:
- Sounder/Models/ - data models for audio blocks
- Sounder/Services/ - audio processing and block management
- Sounder/Views/ - SwiftUI interface components
- Sounder/ViewModels/ - view model layer

**Current Features**:
- Basic audio signal generation (sine, square, triangle, sawtooth)
- Audio output device selection including Bluetooth
- Parameter-driven sound generation

**In Development**:
- Block-based visual signal generator interface
- Drag-and-connect audio processing blocks
- Real-time parameter control
- Signal modulation (AM, FM, ring modulation)
- Audio analysis blocks (spectrum, level meters)
- Configuration save/load functionality

**Recent Changes**:
- Added block-based UI feature specification
- Designed visual block canvas with drag-and-drop
- Created AudioKit Flow integration plan for node editing
- Implemented comprehensive audio block type system
